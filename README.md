# Brain in a Vat Homebrew tap

Third-party casks maintained by Brain in a Vat. This tap is not affiliated with
or endorsed by Homebrew.

Install Writ with:

```sh
brew install --cask braininavatgroup/tap/writ
```

Writ is a macOS menu bar app for macOS 13 and later. It is distributed under
the [PolyForm Noncommercial License 1.0.0](https://github.com/braininavatgroup/writ/blob/main/LICENSE).
